**Svar på frågor om Git**
- Skillnad mellan git add och git commit
Med git add lägger man till de ändrade filer i staging area medan git commit skapar en ny version av ditt lokala repo.

- Branches
Man gör ändringar i branches istället för main för att till exempel testa en ny funktion utan att störa andra delar av projektet.

- Merge
När man gör en merge så slår man ihop alla branches till main.

- Publicering
När man pushar till GitHub kan till exempel andra programmerare eller lärare se din kod. När man publicerar direkt förvandlas det till en hemsida på internet.

- Exkludera fil
För att inte få med en viss fil kan man lägga till en fil som kallas för .gitignore och sedan inuti filen skriver man namnen på det som inte ska visas.
